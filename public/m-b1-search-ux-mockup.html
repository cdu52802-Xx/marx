核心差异 · 6 点

  1. 顶部 hint 文案："不知道搜什么？从这里开始" · 引导探索者用户 / 不强 demand 已知关键词。
  2. 3 分类 entry chip：主要人物 / 核心概念 / 关键时段 · 点 chip 自动填入搜索框 + 自动切到 AFTER 2 分组结果。
  3. 概念命中独立段：搜"异化"时 popover 第 1 段是"§ 概念" / 显示"异化"本身的元信息（Marx 核心 / 1844 手稿）/ 点击直跳定义。
  4. 一级 = 提出者人物：之前 flat list / 现在按 author_id group / 每组显示 "§ 人物名 · N 条主张"。
  5. 二级 = 该人物 claim：缩进 28px / · bullet / 关键词紫色高亮 异化 · 1 行 ellipsis 截断。
  6. 年份小字 italic：右对齐 / 灰色 / editorial 风格 / 给学者用户时序感。

两形态切换规则

  1. 搜索框 click + 输入框空 → 显示 AFTER 1（探索形态）
  2. 用户打字 → 自动切到 AFTER 2（分组结果）
  3. 清空输入 → 切回 AFTER 1（探索形态）
  4. Esc / 点空白 → 关 popover（同 Stage 2 行为）
  5. 键盘 ↑↓ 仍工作 / 跨 section 跳（Marx 最后一条 ↓ → 费尔巴哈第一条）
